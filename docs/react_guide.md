# 🛠️ Guía de React + Vite

Este documento contiene los comandos esenciales para trabajar
con React + Vite.

## 1. Crear un proyecto de React + Vite
Desde la raíz de la aplicación ejecuta los siguientes comandos.

```bash
# 1. Inicializa el proyecto
npm init -y

# 2. Crea un proyecto con Vite
npm create vite@latest

# 3. Instala dependencias
npm install

# 4. Inicia el proyecto
npm run dev
```

## 2. Iniciar el proyecto de React + Vite
Desde la raíz de la aplicación localizate en frontend/ y ejecuta
los siguientes comandos.

```bash
# 1. Instala las dependencias
npm install

# 2. Inicia el proyecto
npm run dev
```
